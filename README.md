🌙 Personal Profile Website

A simple and modern personal profile website built with pure HTML, CSS, and JavaScript.

✨ Features

- 🌌 Dark / Light Mode
- 🎵 Background Music
- 📱 Responsive Design
- ✨ Smooth Scroll & Scroll Animation
- 🎨 Dark Minimalist — Midnight Blue
- 👤 Personal Profile
- 🎮 Hobby Section
- 🌐 Social Media Links
- 📧 Contact Section
- 💾 Theme preference saved with "localStorage"

🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts — Poppins

📁 Project Structure

project/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── profile.jpg
    └── music.mp3

🚀 How to Run

No installation or framework is required.

1. Clone or download this repository.
2. Make sure the "assets" folder contains "profile.jpg" and "music.mp3".
3. Open "index.html" in your browser.

That's it.
